# 90 — Archivo

Documentos completados, fases cerradas, versiones anteriores, contenido obsoleto.

## 📂 Subdirectorios

- **fases-completadas/** — Documentación de fases ya cerradas (validación, entrega, cierre técnico)
- **versiones-anteriores/** — Versiones previas de documentos activos
- **obsoleto/** — Documentos que ya no son vigentes

## 📝 Política

- Nada se borra, todo se archiva
- Los documentos aquí están congelados (lectura solamente)
- Si necesitas activar algo, muévelo a su carpeta correcta (con nuevo frontmatter)
